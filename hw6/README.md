### Все необходимые зависимости
```
pip install -r requirements.txt
```
## Можно запустить с помощью команд
### Основные neat
Тренировка модели
```
make train
```
Играет модель
```
make play-ai
```
Играет человек
```
make play-human
```
### Основные DQN
Тренировка модели
```
make train
```
Играет модель
```
make play
```
